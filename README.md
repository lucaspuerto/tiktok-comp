# Competição TikTok — Dashboard

Leaderboard público da competição de TikTok entre mentorados do Lucas Puerto.

**➜ https://lucaspuerto.github.io/tiktok-comp/**

Este repo só serve o dashboard via GitHub Pages. O `index.html` e o `admin.html`
são gerados e publicados automaticamente a cada rodada (a cada 2h, das 7h às 23h BRT)
pela GitHub Action do repo principal — **não edite os arquivos aqui na mão**, qualquer
mudança é sobrescrita na próxima rodada.
